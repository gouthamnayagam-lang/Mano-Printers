# Inkora Print Studio

A responsive React/Vite starter site for a diary/calendar/custom printing business. Includes CSS 3D-style product visuals, Firebase email/password auth, Firestore order saving, customer order history, an owner order desk, and EmailJS email notifications.

## Quick start

1. Install Node.js LTS.
2. Run `npm install`.
3. Copy `.env.example` to `.env` and fill in Firebase / EmailJS values.
4. Follow `SETUP.md` fully — especially Firebase Authentication, Firestore database, and the rules' owner email.
5. Run `npm run dev` and open the local URL Vite prints.

This project is not connected to a real Firebase / EmailJS account until you add your own settings. Do not use Firebase's open test rules in production. See `SETUP.md` for step-by-step setup, email template variables, troubleshooting, and deployment.
